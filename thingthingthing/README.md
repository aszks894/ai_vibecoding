# Share the claw machine

Send your Windows friends `DefinitelyNotRiggedClawMachine.exe`. They do not
need to install Python. They can double-click the file to play.

This is a Windows executable, so it will not run directly on Chromebooks or
macOS. Some Windows computers may show a SmartScreen warning because the game
is not digitally signed; only run it if you trust who sent it.

The `.spec` file and `build` folder are PyInstaller's build files. The `.exe`
is the file to share.
